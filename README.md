# Startup Team Card Generator (HTML/CSS/JS)

A simple website for **Technopreneurship** where students enter:
- **Startup / Team Name**
- **3 Team Members** (Leader/Founder, Developer, Designer)

Then the website generates a **professional “receipt/card”** and lets you **download it as a PNG** to send to your teacher or class GC.

---

## Features

- ✅ Simple clean design (Wadhwani colors)
- ✅ Fixed 3 roles (Leader/Founder, Developer, Designer)
- ✅ Preview of the professional card
- ✅ Customize the border (style, width, radius, color)
- ✅ **Download as PNG** (ready to send)
